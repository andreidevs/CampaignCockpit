# Лаборатория версий (`lab.py`)

Цикл самоулучшения поверх агента. Агенту не нужен, состояние хранится в Postgres (см. [хранилище](cockpit.md#хранилище)). Доступна роли `admin` в кокпите и через `/api/lab/*`.

```
матрица тестов → детекторы проблем → патч (LLM через privacy gateway или шаблон)
→ новая draft-версия → та же матрица → gate против родителя → candidate / failed → promote (кнопкой)
```

## Версия
Набор настроек из allowlist `PATCH_TARGETS` поверх `agent.py`: константы (`LCB_K`, `PRIOR_STD`, размер пилотов…), флаги эвристик, режим privacy и `LLM_PROMPT_EXTRA` (полный список — [configuration.md](configuration.md#константы-агента)). У каждой цели есть тип и границы, значение вне границ отклоняется. Сам код не копируется. У версии есть `parent_id`, `commit_hash`, `prompt_hash`, `config_hash`, diff от родителя и статус `draft → candidate | failed → promoted`.

## Матрица тестов
На каждую версию:
- `local_eval` на 1 и 10 seed;
- `stress_eval` на 10 миров;
- жёсткие миры (`stress_eval.harsh_world`): эффекты перемешаны между переходами, `keep` — сколько правды осталось в истории. На `keep=0` (30 миров) стратегия без пилотов получает ~1/16 оракула — так в описании среды выглядит боевая среда. На `keep=0.5` — 10 миров. В обычных стресс-мирах без пилотов получается около половины оракула: история там почти верна;
- валидация кампаний;
- бюджет и охват;
- время прогона;
- прогон с выключенным LLM;
- сбой и мусор LLM (`check_llm` + `check_never_empty`).

Около 10 с на версию: прогоны идут параллельно в процессах.

## Детекторы
Находят проблемы с доказательствами. Например, `HIGH_VARIANCE_BETWEEN_SEEDS` («медиана +6.8M, но 4/10 миров в минусе») или `WEAK_LLM_CONTRIBUTION` («рукава LLM добавлены, но ни один не попал в план»). Полный список — в `detect()`.

## Ремедиация и gate
- Issues превращаются в ограниченный патч: либо LLM через тот же privacy gateway (в контексте только issues, метрики и границы настроек), либо шаблон.
- Получается новая версия, она проходит ту же матрицу.
- **Gate**: все must-have тесты пройдены; медиана жёстких миров `keep=0` не упала; медиана `keep=0.5` и стресс-миров упала не больше чем на 3%; худший мир `keep=0` не стал хуже (раньше — «прогонов в минусе не больше»: на границе нуля это монетка); 0 отброшенных кампаний. Если родитель оценён старой матрицей, он сначала перепрогоняется.
- Ответы LLM кэшируются в БД по хэшу промпта (таблица `llm_cache`). Иначе gate сравнивал бы шум модели: один и тот же конфиг давал 6.57M и 7.06M в двух прогонах.

## Promote
Только кнопкой и только из `candidate`: константы переписываются в `agent.py` построчно, `submission.csv` пересобирается без ключа. Коммит — вручную.

Новые эвристики в `agent.py` выключены по умолчанию, при них план совпадает с `submission.csv`: `RANK_BY="lcb"`, `CHANNEL_MU="lcb"` + `UPGRADE_MIN_ROI`, `META_CONTROLLER`, `PILOT_BUDGET_SHARE`. Включает их только версия, прошедшая gate.

## Privacy gateway
`safe_context` → `llm_proxy` → `_parse_llm` в `agent.py`, общий для LLM-эксперта и ремедиации:
- в LLM уходят только ячейки и медианы полей `LLM_FIELDS`;
- ячейки меньше `K_MIN` идут без статистик;
- поле вне allowlist блокирует запрос;
- каждый вызов пишется в аудит;
- режимы: `aggregate_only`, `synthetic_only` (шум, округлённые n), `debug_safe` (ни одного числа об абонентах).

## Первые замеры
10 стресс-миров, живой `gpt-4o-mini`:

| версия | медиана | gate |
|---|---|---|
| baseline, промпт через gateway | 6.57M | — |
| baseline, прежний промпт ([ablation экспертов](experiments.md#ablation-экспертов)) | 7.14M | — |
| `RANK_BY=lcb` | 6.95M | пройден |
| `CHANNEL_MU=lcb`, `UPGRADE_MIN_ROI=1` (предложил LLM) | 6.24M | отклонён |

Разница между двумя промптами — один ответ LLM на прогон, то есть в пределах шума. Без ключа baseline совпадает с `exp_prior` (6.79M).

```bash
python3 lab.py    # self-check: validate, детекторы, gate, round-trip констант, быстрая матрица
```
